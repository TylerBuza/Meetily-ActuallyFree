# Meetily 0.2.24 — Linux desktop preview

For x86_64 desktops using PulseAudio or PipeWire's `pipewire-pulse`. Start with **CPU** unless you want GPU acceleration and have a working Vulkan driver. Install only one backend. DEBs target Ubuntu 24.04 amd64; AppImages require a compatible Linux desktop.

This update keeps the first preview's native Linux capture, default-route handling and playback. It fixes duplicate participants in the meeting header, preserves recording duration after Stop, and improves checkpoint recovery. New Parakeet downloads use pinned revisions. Existing meeting and model storage locations are unchanged.

- DEB: `sudo apt install ./<filename>.deb`
- AppImage: make the download executable, then launch it. If FUSE is unavailable use `APPIMAGE_EXTRACT_AND_RUN=1 ./<filename>.AppImage`.
- Verification: `sha256sum --ignore-missing -c SHA256SUMS.txt` in the download folder.

CI verifies CPU and Vulkan package payloads, headless launch and private virtual-audio tests. That is not a physical microphone, Bluetooth, AMD/Intel inference or installed-upgrade qualification. Large recordings over 256 MiB can be played externally. Share distro/audio-server and device results in [discussion #75](https://github.com/TylerBuza/Meetily-ActuallyFree/discussions/75).
