# Linux desktop preview 1

Meetily – Actually Free for **x86_64 Linux** captures your microphone and computer audio through PulseAudio or PipeWire's `pipewire-pulse` service. Choose **System default** to follow desktop route changes, or pick a specific device to keep it pinned.

**Start with CPU.** Choose the `cpu` DEB or AppImage. Choose `vulkan` instead if you want GPU acceleration and have a working Vulkan driver. CPU and Vulkan are alternatives: install only one. The DEBs target Ubuntu 24.04 amd64. The AppImages need a compatible Linux desktop.

- **DEB:** install the downloaded file with `sudo apt install ./<filename>.deb`.
- **AppImage:** make the downloaded file executable and launch it. If FUSE is unavailable, use `APPIMAGE_EXTRACT_AND_RUN=1 ./<filename>.AppImage`.
- Download `SHA256SUMS.txt` to verify your package: `sha256sum --ignore-missing -c SHA256SUMS.txt`.

**Testing scope.** The Ubuntu 24.04 build verifies both package payloads and launches them in an isolated desktop session. Local testing included synthetic recording, device switching, recovery and playback regressions. An equivalent release-profile build on WSL2 transcribed speech and generated a summary on an RTX 4070 Ti using Vulkan over D3D12. Native-driver coverage, Bluetooth capture and upgrades on real desktops are still limited. Linux in-app playback is limited to 256 MiB per recording; larger files can be opened externally.

**Help test a real meeting:** record a short call, verify both sides are audible, then restart the app and reopen the recording. Please share your distro, audio server, selected build and result in [Linux testing discussion #75](https://github.com/TylerBuza/Meetily-ActuallyFree/discussions/75). No recording upload is needed.
